# CorbolPrompt

**CorbolPrompt** is a tabbed terminal for Windows 10/11 with an AI assistant and a built-in Lisp interpreter. Each tab runs a real shell:

- **PowerShell 7** and **Windows PowerShell**
- **Command Prompt** (cmd)
- **WSL** (Linux) and **Git Bash**, if installed
- **Lisp (CorbolPrompt)**: a small Common Lisp written for the app

Colors, full-screen programs (vi, less, edit...), scrollback, copy and paste all work. On top of that:

- **AI assistant**: explains errors and output and suggests commands, which you run with a click (Claude Code, Claude API, OpenAI-compatible services or a local model on the PC)
- **favorites**: the commands you reuse, with a description, suggested according to the tab's shell
- **Open in CorbolPrompt** in the right-click menu of folders in File Explorer
- tabs come back when you reopen the app, in their folders
- updates from GitHub, with SHA-256 verification

Interface in **English and Italian**; more languages can be added with a text file.
