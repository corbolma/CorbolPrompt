# CorbolPrompt

**CorbolPrompt** è un terminale a schede per Windows 10/11 con un assistente IA e un interprete Lisp integrato. In ogni scheda gira una shell vera:

- **PowerShell 7** e **Windows PowerShell**
- **Prompt dei comandi** (cmd)
- **WSL** (Linux) e **Git Bash**, se installati
- **Lisp (CorbolPrompt)**: un piccolo Common Lisp scritto per l'app

Funzionano colori, programmi a schermo intero (vi, less, edit...), cronologia scorrevole, copia e incolla. In più:

- **assistente IA**: spiega errori e output e propone comandi, che esegui tu con un clic (Claude Code, API Claude, servizi compatibili OpenAI o un modello locale sul PC)
- **preferiti**: i comandi da riusare, con descrizione, suggeriti in base alla shell della scheda
- **Apri in CorbolPrompt** nel menu del tasto destro delle cartelle di Esplora file
- le schede si riaprono alla riapertura, nelle loro cartelle
- aggiornamenti da GitHub, con verifica dello SHA-256

Interfaccia in **italiano e inglese**; altre lingue si aggiungono con un file di testo.
